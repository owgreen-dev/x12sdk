x12sdk playground

Check, tabulate, generate and match HIPAA X12 health care files: claims (837P/I/D), remittances (835), eligibility (270/271), claim status (276/277) and enrollment (834). Powered by x12sdk, an open-source Python library.

🔒 Runs entirely in your browser. Files you open are never uploaded.
Loading Python in your browser… the first visit downloads about 14 MB; later visits are quick.

Valid 835 and 837 files also become a table with one row per service line, ready to download as CSV.

Every file is synthetic: invented patients, providers and payers, no PHI. The same seed always makes the same file.
